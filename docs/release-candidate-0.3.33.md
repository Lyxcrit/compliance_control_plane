# Release Candidate 0.3.33

- Made the Requirements Explorer action explicit with an `Open check` cell.
- The cell opens Check Detail with the selected framework and requirement keys.
- Removed the new-tab dependency from the Requirements-to-Check handoff.
- Added regression assertions for the visible action and cell drilldown.

The Requirements Explorer remains a navigation aid. Check Detail is the authoritative workspace for implementation guidance, technical verification, evidence, and assessment context.
