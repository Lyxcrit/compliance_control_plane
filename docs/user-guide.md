# User Guide

## Administrator

1. Install the package and open Framework Setup.
2. Select only applicable frameworks.
3. Define audit scopes and register systems with business and technical ownership.
4. Confirm optional integration health. Missing products remain Not assessed.
5. Review the saved searches before enabling scheduled collection.

## Auditor

1. Open Readiness or Audit Review and select the framework and scope.
2. Open a check to read its source, verification route, implementation steps, and evidence expectations.
3. Use Assessment for the decision and Evidence for the artifacts reviewed.
4. Treat Pass as a reviewed conclusion, not merely a technical signal.
5. Use Audit Package for the fixed-period export and retain its manifest with the registers.

## Control owner

1. Use Measurement Center when an executable technical check is available.
2. Run the check, inspect its observed and expected values, and save the result as measurement evidence.
3. For document or hybrid checks, attach a document URL or Splunk reference, version, reviewer, review time, and acceptance notes.
4. Use Findings and Remediation to assign an owner role, due date, concrete fix, and retest.
